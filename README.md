## 快速開始

1. 用瀏覽器開啟上面的網址，直接就能記帳，不需要註冊。
2. 在「記帳明細」頁最上方的輸入框打 `午餐 120`，按 Enter，完成一筆支出。
3. 想安裝成 App：手機用瀏覽器的「加入主畫面」，電腦用 Chrome／Edge 網址列的安裝圖示。安裝後可離線使用。
4. 第一次開啟（桌面版 Chrome／Edge）會詢問是否設定備份資料夾，建議設定；之後每次記帳都會自動備份。
5. 手機沒有資料夾備份功能，請養成定期到「資料管理」匯出的習慣（見[備份](#備份匯出與匯入)）。

> PWA 必須使用 HTTPS（或 `localhost`）才能安裝與離線。直接雙擊開啟 `index.html` 可以記帳，但沒有安裝、離線與更新提示功能。

## 功能說明

### 三個主頁面

頂部分頁為「記帳明細」、「數據圖表」、「預算管理」，在手機上可以左右滑動切換。右上角三個按鈕依序是外觀設定、資料管理、搜尋。

### 記帳

| 功能 | 說明 |
|---|---|
| 快速記帳 | 一行文字自動判斷日期、類別、金額、收支，語法見[下一節](#快速記帳語法) |
| 手動記帳 | 金額優先，類別以按鈕選擇，並依最近與常用程度排序；可選日期與備註 |
| 預設類別 | 支出：餐飲、交通、購物、日用品、娛樂、居住、醫療、學習、其他；收入：薪資、獎金、投資、兼職、其他 |
| 自訂類別 | 「管理自訂類別」可新增、改名、刪除。改名會同步更新所有舊紀錄；刪除時可選擇把既有紀錄移到「其他」。類別名稱最長 20 字 |
| 常用項目 | 最近 90 天內「類型＋類別＋備註＋金額」完全相同、且出現 2 次以上的項目（最多 6 個），一鍵再記一筆 |
| 常用備註 | 手動記帳時，備註欄下方會列出最近 30 天常用的備註（同收支類型，目前選的類別優先）。**已填金額時，點一下備註就以目前選的類別直接新增**，新增後 7 秒內可復原；還沒填金額則只填入備註，並跳到金額欄。輸入文字時會變成符合的備註建議 |
| 編輯 | 點明細左側的類別／備註區域即可修改日期、類型、類別、金額、備註，也可在此刪除 |
| 復原 | 新增或刪除後會跳出提示，7 秒內可按「復原」 |

### 明細清單

- 每筆紀錄：左側顯示類別（粗體）與備註，右側顯示金額與日期，最右邊是刪除鈕。沒有備註時該行留白。
- 依月份篩選，可切換上一個月／下一個月，也可按「顯示全部」。
- 排序：日期新到舊、日期舊到新、金額高到低、金額低到高。
- 頂部摘要顯示目前篩選範圍的總收入、總支出與結餘。

### 搜尋

右上角搜尋按鈕開啟獨立的搜尋頁：

- 關鍵字會同時比對日期、收支類型、類別、金額與備註。
- 可指定起訖日期，**預設為今年 1 月 1 日到今天**；清空日期即不限範圍。
- 結果同樣可依日期或金額排序，點任一筆可直接編輯或刪除。

### 數據圖表

切換「本週／本月／本年度／全部」，並可前後翻頁：

| 範圍 | 趨勢圖的分組方式 |
|---|---|
| 本週 | 依日 |
| 本月 | 依週 |
| 本年度 | 依月 |
| 全部 | 依年 |

另有類別佔比（甜甜圈圖）與該期間的收支明細。

### 預算管理

- 設定「每月預算」，並追蹤本月支出進度條。
- 進度到 80% 轉為警示色，達 100% 以上顯示「已超支」。
- 預算以月份為單位保存，可在「預算管理」頁修改。

### 外觀

右上角「外觀設定」可選整體色調（淺色／深色／跟隨系統）與 9 種介面顏色（紅、橘、黃、綠、藍、靛、紫、黑、白）。

### PWA 特性

可安裝到主畫面、離線使用；桌面／主畫面圖示支援捷徑（新增支出、新增收入），開啟後會直接聚焦金額欄位。

## 快速記帳語法

在輸入框輸入一行文字，系統會自動拆解：

| 輸入 | 結果 |
|---|---|
| `午餐 120` | 支出、餐飲、$120、今天 |
| `昨天 捷運 30` | 支出、交通、$30、昨天 |
| `前天 全聯 560` | 支出、日用品、$560、前天 |
| `薪水 +30000` | 收入、薪資、$30,000 |
| `停車 -50` | 強制視為支出 |
| `咖啡 85元` | 金額後可接「元／塊／圓」 |
| `買鞋 1,280` | 金額可含千分位逗號 |

規則細節：

- **日期詞**：`前天`、`昨天`／`昨日`、`今天`／`今日`，可放在句子任何位置；沒寫就是今天。
- **金額**：取句子中**最後一個**數字，可帶 `+`、`-`、`$`。金額必須大於 0。
- **收支**：數字前加 `+` 為收入、加 `-` 為支出；沒有符號時，命中你的收入類別名稱或內建收入關鍵字（薪水、年終、股利、接案…）就判為收入，其餘為支出。
- **類別**：優先比對你自己的類別名稱（含自訂類別，名稱較長的優先），再比對內建關鍵字（捷運、全聯、蝦皮、房租、掛號、課程…），都沒中就歸「其他」。
- **備註**：扣掉日期詞與金額後剩下的文字；如果剩下的文字就等於類別名稱，備註留白。

輸入後可先在畫面上確認再送出，類別判斷不準時，請改用手動記帳，或用「管理自訂類別」建立自己的類別，之後同名輸入就會優先命中。

## 備份、匯出與匯入

右上角「資料管理」是所有備份功能的入口。

### 備份方式一覽

| 方式 | 說明 |
|---|---|
| App 內快照 | 每次異動後自動存當天快照，保留最近 7 份，可在「資料管理」還原。存在瀏覽器內，**清除網站資料會一起消失** |
| 備份資料夾（Chrome／Edge 桌面版） | 首次開啟時選擇資料夾，之後每次記帳（約 1.5 秒後）自動寫入。重開瀏覽器後可能需要重新授權；瀏覽器不允許直接選桌面、文件、下載等系統根資料夾，請選其下的子資料夾 |
| 匯出 JSON 到備份資料夾 | 把完整 JSON 備份寫入已選資料夾（尚未選擇時會先請你選）。瀏覽器不支援資料夾寫入（手機、Firefox、Safari）時，按鈕會變成「下載 JSON 備份」，直接下載檔案 |
| 匯出 CSV 並分享 | 使用瀏覽器分享功能送出 CSV，同時存入已選資料夾；不支援分享時改為下載。原生檔案分享需要瀏覽器與裝置支援（例如 Android Chrome） |
| 匯入 JSON／匯入 CSV | 合併匯入，匯入前會顯示確認視窗並先暫存目前記錄 |

超過「未備份提醒」天數（預設 3 天，可設 1–365）沒有備份，首頁會出現提醒。匯出成功、下載、或成功寫入備份資料夾都算一次備份。

### 備份資料夾的檔案

| 檔名 | 內容 |
|---|---|
| `smart-ledger_latest.json` | 最新備份，每次變更都會更新 |
| `smart-ledger_2026-10-16.json` | 當日備份；每天第一次記帳與頁面進入背景時更新，保留最近 7 天 |
| `smart-ledger_2026-10-16.json`（手動匯出） | 「匯出 JSON」產生的同名檔，內容格式與上面相同 |
| `smart-ledger_2026-10-16.csv` | 「匯出 CSV」產生的檔案 |

早期版本留下的 `ledger-日期.json` 仍會依 7 天規則清除；舊的 `ledger-latest.json` 不會自動刪除，可手動清理。

### 匯入規則

**匯入 JSON**

- 同時支援 v2 備份與舊版的純記錄陣列。
- 確認視窗會告訴你：匯入幾筆、其中幾筆與現有 ID 相同（**會被覆蓋**）、幾筆格式無效（略過）、以及將套用哪些設定。
- 備份內的設定處理方式：預算同月份覆蓋、自訂類別與現有合併、提醒天數與外觀直接套用。
- 如果檔案是別的 App 產生的、或 `app` 欄位不符，會被拒絕；版本較新時會提醒可能有欄位無法辨識。

**匯入 CSV**

- 以 `ID` 欄合併，相同 ID 覆蓋既有紀錄。
- 舊版沒有 ID 欄的 CSV 仍可匯入，但每列都會當成新紀錄，**重複匯入會產生重複資料**。
- CSV 只含記錄，不含預算與設定。

**暫存與還原**

JSON 匯入、CSV 匯入、還原快照、刪除所有記錄之前，系統都會先把當時的記錄暫存起來，在「資料管理」的快照清單最上方會出現「還原／匯入／清空前的暫存」，按一下即可還原。暫存只有記錄，不含設定。

## 資料格式規格

### JSON（完整備份，建議首選）

手動匯出、備份資料夾的自動備份、CWMoney 轉換工具輸出，全部使用同一種格式：

```json
{
  "app": "smart-ledger",
  "version": 2,
  "exportedAt": "2026-10-16T09:30:00.000Z",
  "records": [
    { "id": 1760000000001, "date": "2026-10-16", "type": "expense",
      "category": "餐飲", "amount": 120, "note": "午餐" }
  ],
  "settings": {
    "budgets": { "2026-10": 20000 },
    "customCategories": { "expense": ["寵物"], "income": [] },
    "backupReminderDays": 3,
    "theme": "blue",
    "colorMode": "dark"
  }
}
```

| 欄位 | 規則 |
|---|---|
| `records[].id` | 正整數，匯入時相同 ID 覆蓋；缺少時由 App 補上 |
| `records[].date` | `YYYY-MM-DD` |
| `records[].type` | `expense` 或 `income` |
| `records[].category` | 最長 20 字，空白時為「其他」 |
| `records[].amount` | 大於 0、不超過 10¹⁰，取到小數第 2 位 |
| `records[].note` | 最長 200 字 |
| `settings` | 可省略；每個子欄位都會驗證，無效的會被忽略 |

舊版（v1）是只有記錄的純陣列，匯入時仍然相容。

### CSV（給 Excel 分析）

- 欄位：`ID, 日期, 類型, 類別, 金額, 備註`，類型為「收入」或「支出」。
- UTF-8 含 BOM，Excel 直接開啟中文不會亂碼；換行為 CRLF。
- 以 `=`、`+`、`-`、`@` 開頭的文字會加上 `'` 前綴，避免被 Excel 當成公式執行；匯入時會自動還原。

### App 內快照

只包含記錄（不含設定），存在瀏覽器的 IndexedDB 裡，最多 7 份。

## CWMoney 轉換工具

`cwmoney-converter.html` 是獨立的單一 HTML 檔，可直接雙擊開啟，不需要網路，檔案不會上傳。

1. 選擇 CWMoney 的備份檔（`.iDB`），或本 App 的 JSON。
2. 設定 CWMoney 的日期時區（台灣為 UTC+8，只影響 `.iDB`）。
3. 在「類別對應」把 CWMoney 的舊類別逐一對到本 App 的類別，也可輸入自訂類別；對應結果會即時反映在預覽、JSON 與 CSV。
4. 下載 JSON（格式與本 App 的匯出相同）或 CSV，再到本 App 的「資料管理」匯入。

注意事項：

- 非支出／收入的紀錄，或金額、日期無效的紀錄會被略過，並在畫面上列出數量。
- 外幣紀錄的金額**不會換算**，只在備註標註匯率，請自行核對。
- 輸入若是本 App 的 v2 備份，備份內的設定會原樣保留到輸出的 JSON。
- 輸出檔名為 `smart-ledger_日期.json／.csv`；CSV 含 ID 欄，重複匯入同一份不會產生重複資料。

## 離線、更新與多視窗

- **離線**：Service Worker 會預先快取所有檔案。開啟頁面時優先向網路取最新的 `index.html`，沒網路時用快取；其餘靜態檔案先用快取、背景更新。
- **新版本提示**：發布新版後，已開啟的 App 會跳出「有新版本可用 → 立即更新」；App 開著超過 1 小時再切回前景，也會自動檢查更新。
- **多視窗同步**：同時開著多個視窗或分頁（例如 PWA 與瀏覽器分頁）時，任一視窗新增、修改、刪除，其他視窗會在約 0.3 秒內自動更新。若別的視窗刪掉了你正在編輯的那筆，編輯視窗會自動關閉並提示。
- **儲存空間保護**：首次自動備份後會向瀏覽器申請「持久儲存」，降低資料被系統自動清除的機會（是否核准由瀏覽器決定）。

## 資料與隱私

- 所有記帳資料存在瀏覽器的 IndexedDB，**不會上傳到任何伺服器**；GitHub 只提供網頁檔案。
- 資料以「瀏覽器＋網址」為單位：手機和電腦各自獨立，換網址或換瀏覽器就是一份全新的空資料。
- 跨裝置請用「匯出 JSON」再到另一台「匯入 JSON」（合併匯入，相同 ID 覆蓋）。
- 「資料管理 → 診斷資訊」會顯示儲存用量、持久儲存狀態、快取版本、瀏覽器功能支援與最近 20 筆錯誤紀錄；錯誤只存在本機，按「複製診斷資訊」才會離開你的裝置，內容包含瀏覽器版本字串，貼給別人前請自行檢查。

## 檔案結構與部署

```
index.html              # 主程式（HTML + JS）
tailwind.css            # 預先編譯的樣式
manifest.webmanifest    # PWA 設定
sw.js                   # Service Worker（離線快取與更新）
icons/                  # App 圖示（4 張 PNG）
cwmoney-converter.html  # CWMoney 轉換工具（獨立檔案，可放在任何地方）
tailwind.config.js, input.css   # 只有要重新編譯樣式時才需要
```

### 部署到 GitHub Pages

專案本身是純靜態檔案，把上面的檔案放進 repository 並啟用 GitHub Pages 即可，不需要建置步驟。

### 發布新版的注意事項

1. **`index.html` 和 `sw.js` 一起上傳**。
2. 只要改了 `index.html`、`tailwind.css`、圖示或 `manifest.webmanifest`，就要把 `sw.js` 第 2 行的 `CACHE` 版本號加 1（例如 `ledger-v9` → `ledger-v10`），否則使用者的手機可能一直用舊快取。
3. 使用者開啟 App 後會看到「有新版本可用」提示，按下即更新。
4. 新增 Tailwind 的 class 後，需要用 `tailwind.config.js` 與 `input.css` 重新編譯出 `tailwind.css`，因為正式版沒有內建編譯器。

## 常見問題

**沒有出現安裝選項？**
確認網址是 HTTPS（或 localhost），並且不是無痕視窗。iOS 請用 Safari 的「分享 → 加入主畫面」。

**更新後還是舊畫面？**
先等待畫面出現「有新版本可用」並按「立即更新」；沒有出現的話，完全關閉 App 再重新開啟。

**舊版資料不見了？**
網址不同就是不同的儲存空間，請在舊網址「匯出 JSON」，再到新網址「匯入 JSON」。

**匯出 JSON 時出現「分享失敗（NotAllowedError）」？**
這是瀏覽器不允許分享該類型檔案或不接受目前的操作時機。現在 JSON 匯出已改為直接寫入備份資料夾（不支援的瀏覽器會改為下載），不再使用分享；CSV 分享失敗時，提示旁會有「改為下載」按鈕。

**手機上怎麼備份？**
手機瀏覽器不支援寫入資料夾，請定期在「資料管理」按「匯出 JSON」下載檔案，再存到雲端硬碟或傳給自己；也可以用「匯出 CSV 並分享」送到其他 App。

**備份資料夾提示需要重新授權？**
關閉瀏覽器後權限可能失效，開啟「資料管理」按「選擇備份資料夾」或再次匯出，依提示允許即可。

**選資料夾時被拒絕？**
瀏覽器不允許選桌面、文件、下載等系統根資料夾，請在其中建立一個子資料夾（例如 `智慧記帳備份`）再選。

**匯入後數字不對或有重複？**
匯入 CSV 時沒有 ID 欄會一律新增，重複匯入同一份就會重複。可以到「資料管理」的快照清單，選最上方的「還原／匯入／清空前的暫存」退回匯入之前的狀態。

**不小心刪光了？**
同樣在快照清單選「還原／匯入／清空前的暫存」，或選最近的每日快照。「刪除所有記錄」不會移除預算與既有快照。

**瀏覽器清除網站資料之後怎麼辦？**
IndexedDB 與 App 內快照會一起消失，請從備份資料夾或你匯出的 JSON 檔匯入還原，所以請至少保留一份存放在瀏覽器之外的備份。

**同時開兩個視窗會不會互相覆蓋？**
不會，各視窗的變更會即時同步；只有「同一筆紀錄在兩個視窗同時編輯」時，後儲存的會覆蓋先儲存的。

**回報問題時要附上什麼？**
到「資料管理 → 診斷資訊」按「複製診斷資訊」，連同操作步驟一併提供。
