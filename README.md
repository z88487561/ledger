# 智慧記帳

離線可用、資料只存在你自己裝置上的個人記帳 PWA。純靜態網頁，沒有後端、沒有帳號、沒有追蹤。

[https://z88487561.github.io/ledger/](https://z88487561.github.io/ledger/)

## 功能

- **快速記帳**：輸入 `午餐 120`、`昨天 捷運 30`、`薪水 +50000` 就能自動判斷類別、金額和日期
- **手動記帳**：金額優先、類別按鈕（依最近與常用排序）、可自訂類別
- **常用項目**：近 90 天重複出現的項目，一鍵記
- **編輯／刪除**：點明細可編輯；刪除後可復原
- **圖表分析**：類別佔比、收支趨勢與期間明細；本週／全部逐日、本月按週、本年度按月
- **快速瀏覽**：三個主頁面可左右滑動切換；記帳明細底部可搜尋所有日期的紀錄
- **匯出 CSV**：一鍵匯出給 Excel 分析
- **月預算**：設定每月預算並追蹤進度
- **自動備份**：每日快照（保留 7 份）、電腦自動寫入備份資料夾、可自訂未備份提醒天數（預設 3 天）
- **PWA**：可安裝到主畫面、離線使用、桌面捷徑（新增支出／收入）；可選淺色、深色或跟隨系統

## 檔案結構

```
index.html              # 主程式（HTML + JS）
tailwind.css            # 預先編譯的樣式
manifest.webmanifest    # PWA 設定
sw.js                   # Service Worker（離線快取）
icons/                  # App 圖示（4 張 PNG）
tailwind.config.js, input.css   # 只有要重新編譯樣式時才需要
```

> PWA 必須使用 HTTPS（或 `localhost`）才能安裝與離線。直接雙擊開啟 `index.html` 可以記帳，但沒有安裝和離線功能。

```

## 資料與隱私

- 所有記帳資料存在瀏覽器的 IndexedDB，**不會上傳到任何伺服器**；GitHub 只提供網頁檔案
- 資料以「瀏覽器 + 網址」為單位，手機和電腦各自獨立，換網址或換瀏覽器就是一份新的空資料
- 跨裝置請用「匯出備份／匯入備份」（匯入為合併，相同 id 會覆蓋）


## 備份

點右上角「資料管理」：

可在此設定未備份提醒天數（1–365 天，預設 3 天），或刪除所有記帳明細。刪除明細不會移除預算與既有備份快照。

| 方式 | 說明 |
|---|---|
| App 內快照 | 每次異動後自動存當天快照，保留最近 7 份，可還原。存在瀏覽器內，清除網站資料會一起消失 |
| 備份資料夾（Chrome／Edge 桌面版） | 首次開啟時可選擇資料夾；自動備份、JSON 備份與 CSV 都會直接寫入所選資料夾，不會另外建立 `backup/`。自動快照保留 7 天。重開瀏覽器後可能需要重新授權。不能直接選桌面、文件、下載等根資料夾 |
| 匯出並分享 | 使用瀏覽器檔案分享功能傳送 CSV，並將可還原的 JSON 備份寫入已選資料夾；分享不支援或失敗時會下載 CSV。原生檔案分享需瀏覽器與裝置支援（例如 Android Chrome），超過設定天數沒備份時首頁會提醒 |

iOS 對長時間未開啟的網站可能清除儲存資料，請務必加到主畫面並定期匯出。

## 匯出 CSV（Excel）

「資料管理」→「匯出 CSV」會將全部紀錄直接存入所選備份資料夾；若瀏覽器不支援資料夾寫入或未授權，則改為下載。欄位為 `日期, 類型, 類別, 金額, 備註`，UTF-8 含 BOM，Excel 直接開啟中文不會亂碼。CSV 只供分析，不能匯入還原，也不算備份；備份請用 JSON。


## 瀏覽器支援

近兩年的 Chrome、Edge、Safari（iOS 15.4+）、Firefox 皆可使用。自動寫入備份資料夾僅支援 Chrome／Edge 桌面版。

## 常見問題

- **沒有出現安裝選項？** 確認網址是 HTTPS，
- **更新後還是舊畫面？** 完全關閉 App 再開
- **舊版資料不見了？** 網址不同就是不同儲存空間，請在舊網址匯出，再到新網址匯入
